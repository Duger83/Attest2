# Attest2# Анализ финансовой отчетности российских компаний (RFSD 2023)

## Описание проекта

Данный проект выполнен в рамках промежуточной аттестации по курсу. Проведен анализ данных из базы RFSD (Russian Financial Statements Database) — открытой коллекции годовой финансовой отчетности российских компаний за 2011-2024 годы.

## Источник данных

Использованы реальные данные из базы [RFSD](https://github.com/irlcode/RFSD) (Russian Financial Statements Database) за 2023 год. 

Файл `part-0.parquet` скачан вручную с [Hugging Face](https://huggingface.co/datasets/irlspbru/RFSD/tree/main/RFSD/year=2023) и содержит финансовые показатели компаний в формате Parquet. **Сам файл данных не загружен в репозиторий из-за большого размера (560 МБ)** — для воспроизведения анализа его необходимо скачать по ссылке выше и поместить в корень проекта.

Для анализа отобраны 1000 случайных строк и 20 ключевых финансовых колонок.

## Структура репозитория

- `attestation2_analysis.ipynb` — Jupyter Notebook с полным анализом данных
- `part-0.parquet` — данные финансовой отчетности (загружены вручную с Hugging Face)
- `requirements.txt` — зависимости для запуска проекта
- `.gitignore` — исключения для Git

## Выполненные шаги анализа

1. **Описательная статистика** — рассчитаны основные метрики для 438 компаний с корректной отчетностью после фильтрации нулевых и аномальных значений.

2. **Гистограммы и выбросы** — построены распределения выручки, чистой прибыли и активов. Выявлено, что верхний 1% компаний (5 из 438) — это крупные предприятия с выручкой более 4,5 млрд руб.

3. **Матрица корреляции** — найдены сильные взаимосвязи между финансовыми показателями:
   - Выручка и себестоимость: r = 0,994
   - Прибыль до налогов и чистая прибыль: r = 0,999
   - Активы и пассивы: r = 1,000 (балансовое тождество)

4. **Диаграмма рассеивания** — визуализирована зависимость выручки от себестоимости. Выявлено, что у 11,6% компаний себестоимость превышает выручку (отрицательная валовая прибыль). Медианная рентабельность по валовой прибыли составляет 9%.

5. **Выводы** — подтверждены бухгалтерские тождества, выявлена логнормальная структура распределения финансовых показателей, отмечено сильное неравенство размеров компаний в выборке.
